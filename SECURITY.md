# Bảo mật / Security

**Tiếng Việt.** Nếu bạn tìm thấy lỗ hổng bảo mật (ví dụ: bộ cập nhật cài một tệp không phải bản phát hành, metadata còn sót sau khi ứng dụng báo đã xoá), đừng mở issue công khai. Hãy báo riêng qua [GitHub Security Advisories](https://github.com/thientrile/exif-remover/security/advisories/new). Ghi rõ phiên bản, các bước tái hiện và tệp mẫu không chứa dữ liệu riêng tư. Nếu không dùng được GitHub, nhắn riêng qua [Telegram](https://t.me/liguni0202) (không gửi tệp có dữ liệu riêng tư). Tôi sẽ trả lời trong vòng 7 ngày.

**English.** To report a vulnerability (for example the updater accepting a file that is not an official release, or metadata left behind after the app says it is clean), do not open a public issue. Report it privately via [GitHub Security Advisories](https://github.com/thientrile/exif-remover/security/advisories/new) with the version, steps to reproduce and a sample file without private data. If you cannot use GitHub, message privately on [Telegram](https://t.me/liguni0202) (do not send files with private data). Expect a reply within 7 days.

Only the latest release is supported; the in-app updater moves you to it.
