## Tiếng Việt

### Báo lỗi hoặc góp ý

Mở một Issue trên GitHub: https://github.com/thientrile/exif-remover/issues

Cần tài khoản GitHub (miễn phí). Hãy ghi:

1. Phiên bản ứng dụng và phiên bản Windows.
2. Bạn đã làm gì, mong đợi gì, và điều gì xảy ra.
3. Loại tệp (ví dụ JPG, HEIC, MP4, PDF), **không cần gửi chính tệp**.
4. Nếu được, đoạn liên quan trong nhật ký lỗi `%LOCALAPPDATA%\ExifRemover\logs\app.log`.

### Bảo vệ quyền riêng tư khi báo lỗi

Issue trên GitHub là **công khai**.

- **Không đăng ảnh, video, PDF cá nhân** hay ảnh chụp màn hình có thông tin riêng.
- Trước khi dán nhật ký, **xoá tên người dùng Windows và tên thư mục riêng** khỏi đường dẫn (ví dụ đổi `C:\Users\TenBan\...` thành `C:\Users\<user>\...`).

### Tự xử lý nhanh

- **Muốn khôi phục tệp gốc?** Mở nút **Bản sao lưu** trong ứng dụng, hoặc tìm thư mục `<tên thư mục>_backup-NĂM-THÁNG-NGÀY` cạnh thư mục gốc.
- **Không muốn ứng dụng kết nối mạng?** Tắt kiểm tra cập nhật trong ứng dụng (bản Microsoft Store vốn không kết nối mạng).
- **Gỡ sạch?** Gỡ ứng dụng, rồi xoá thủ công `%APPDATA%\ExifRemover` và `%LOCALAPPDATA%\ExifRemover`.
- **Ảnh AI vẫn bị nhận diện là AI?** Đây là giới hạn đã biết, xem [DISCLAIMER](DISCLAIMER.md).

## English

### Report a bug or give feedback

Open an Issue on GitHub: https://github.com/thientrile/exif-remover/issues

You need a (free) GitHub account. Please include:

1. App version and Windows version.
2. What you did, what you expected, and what happened.
3. The file type (e.g. JPG, HEIC, MP4, PDF). **You do not need to send the file itself.**
4. If possible, the relevant part of the error log `%LOCALAPPDATA%\ExifRemover\logs\app.log`.

### Protect your privacy when reporting

GitHub Issues are **public**.

- **Do not post personal photos, videos or PDFs**, or screenshots showing private information.
- Before pasting a log, **remove your Windows user name and private folder names** from paths (e.g. change `C:\Users\YourName\...` to `C:\Users\<user>\...`).

### Private contact

For privacy, security or legal matters you don't want to post publicly: message on Telegram https://t.me/liguni0202

### Response time

This is a free, personal project. The developer tries to answer but **cannot promise a response time**, except for personal-data rights requests (answered within 30 days, see [PRIVACY](PRIVACY.md)).

### Quick self-help

- **Need your original files back?** Use the **Backups** button in the app, or find the `<folder name>_backup-YYYY-MM-DD` folder next to your original folder.
- **Don't want the app to go online?** Turn off update checks in the app (the Microsoft Store version never goes online).
- **Remove everything?** Uninstall the app, then delete `%APPDATA%\ExifRemover` and `%LOCALAPPDATA%\ExifRemover` by hand.
- **AI image still detected as AI?** That is a known limit, see [DISCLAIMER](DISCLAIMER.md).
