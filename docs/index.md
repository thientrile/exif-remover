# Tinh Ảnh (StarVeil)

Xoá metadata ảnh · Photo Metadata Remover. Ánh sao & Bầu trời · by @thientrile

Ứng dụng Windows xoá thông tin ẩn (EXIF, GPS, XMP, IPTC, C2PA) khỏi ảnh, video và PDF, chạy hoàn toàn trên máy bạn.
A Windows app that removes hidden metadata (EXIF, GPS, XMP, IPTC, C2PA) from photos, videos and PDFs, entirely on your computer.
